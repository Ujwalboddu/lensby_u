# lensby_U photography portfolio

A responsive, monochrome black-and-white photography portfolio.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Safari, or Firefox.
3. Keep an internet connection active so Instagram's public photo-post embeds and Google Fonts can load.

## Instagram posts
The gallery embeds the nine Instagram photo posts supplied by the owner. Reels are not included. Instagram controls the embedded post UI and may require the posts to be public and embeddable.

For the cleanest, most seamless image gallery, replace Instagram embeds with original image files supplied by the photographer.
